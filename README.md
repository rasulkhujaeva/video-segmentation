# Color-Based Video Segmentation and Decision Support System

This project focuses on color-based video segmentation using image processing and computer vision techniques. The system applies preprocessing, color space conversion, and clustering algorithms to segment video frames and evaluate results through a decision support mechanism.

## Technologies

* Python
* OpenCV
* Image Processing
* Computer Vision

## Features

* Video frame processing
* Color-based segmentation
* Decision support analysis
* Performance evaluation

Developed for academic purposes.
